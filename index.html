Do / Don’t

Done

Logo usage rules for all OE5XRX brand assets.

Do

  • ✓
    Use currentColor The logo inherits the surrounding text colour. It adapts to light and dark contexts automatically — no manual colour overrides needed.
  • ✓
    Maintain clear space Leave a margin of at least the height of the “O” in the wordmark around all sides of the logo.
  • ✓
    Respect minimum size Mark: minimum ~24 px height. For favicons and anything 32 px or smaller, use favicon.ico instead of the full SVG.
  • ✓
    Check contrast Ensure sufficient contrast between logo and background. Use the brand primary on white or the white variant on dark backgrounds.
  • ✓
    Inline SVG with color: CSS Embed the mark inline and set colour via CSS color property for full theme integration.

Don’t

  • ✗
    Add a border or frame The logo is intentionally borderless. Adding a box or rounded container changes the visual weight and breaks the brand language.
  • ✗
    Apply arbitrary colours Only currentColor, brand primary #123B54, or white are approved. Do not fill with other colours.
  • ✗
    Distort or rotate Scale uniformly. Do not squeeze, stretch, skew, or rotate the logo or any of its components.
  • ✗
    Place mark on busy backgrounds Avoid placing the mark directly on textured or photographic backgrounds without a solid backing surface to ensure legibility.
  • ✗
    Use full SVG below 32 px The multi-path SVG loses legibility at small sizes. Use favicon.ico or the raster PNGs instead.

currentColor in practice

The mark embedded inline next to text — it picks up the parent color automatically:

Body text colour — color: var(--text)
Primary brand colour — color: var(--primary)
White on primary bg — color: #fff
